# Дисбалансы позиций на фьючерсах

Исследовательский проект об изменениях длинных и коротких позиций на срочном рынке Московской биржи. Код собирает дневные отчёты по категориям участников, сопоставляет их с ценами, объёмом и спредами и строит графики по отдельным контрактам.

- [Загрузка отчётов](notebooks/moex-position-download.ipynb) и [сборка таблицы позиций](notebooks/daily-position-reports.ipynb).
- [Котировки и спреды](notebooks/merge-quotes-and-spreads.ipynb). Объединение позиций с рыночными рядами и [расчёт спредов по тикам](notebooks/finam-tick-data-and-spreads.ipynb).
- [Сравнение позиций](notebooks/compare-position-changes.ipynb). Динамика групп участников и движения цен по контрактам.
- [VPIN](notebooks/vpin-local-ticks.ipynb) и [PIN](R/pin-estimation.Rmd). Эксперименты с показателями дисбаланса объёмов и вероятностью информированной торговли. В папке [R](R/) также есть расчёт теоретической цены фьючерса.

Чтобы открыть ноутбуки, установите `python -m pip install -r requirements.txt` и запустите `jupyter lab` из корня репозитория. Для обработки отчётов положите дневные CSV в `data/IN/` и создайте папку `data/OUT/Processed/`. Ноутбук обработки сохранит сводную таблицу в `data/OUT/`. Остальные ноутбуки используют её, дополнительные исторические котировки и выходные папки, указанные в ячейках.

Это архив исследовательского кода. Исходные рыночные данные и результаты расчётов нужно подготовить отдельно. Скрипты используют форматы и адреса источников, доступные на момент работы.
